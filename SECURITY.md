# Security policy

graphersal-memory handles agent transcripts and memories, which can contain sensitive data. We
take reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub's security advisories:
[Report a vulnerability](https://github.com/graphersal/graphersal-memory/security/advisories/new).

Include what you found, how to reproduce it, and the version (`graphersal-memory --version`) and
platform. We will acknowledge the report, keep you informed, and credit you in the advisory if
you wish.

## Scope

Issues in graphersal-memory itself are in scope: the daemon and its socket, the shim, install and
uninstall, import and export, and data handling. Vulnerabilities in the graph engine belong to
[Graphersal's security policy](https://github.com/graphersal/graphersal/security).

## Supported versions

There is no release yet. Once there is, fixes go into the latest release.
